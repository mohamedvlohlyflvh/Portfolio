# Hymerious — Portfolio

**Personal portfolio of Muhammed Said — frontend-first full-stack developer.**
Brutalist dark design, GSAP-driven motion, originkit animation components.

## ✨ Highlights

- **Hero** with scramble-decode subtitle animation
- **Selected work** — asymmetric bento grid (1×1 mobile → 12-col desktop) featuring [Qestak](https://github.com/mohamedvlohlyflvh/Qestak) and [Hymeria Toolkit](https://github.com/mohamedvlohlyflvh/Hymerious)
- **Originkit** animation components (falling text, infinite text passage) vendored and locally patched
- Fully responsive — see `full-desktop.png` / `full-mobile.png` in `docs/screenshots/`

## 🧱 Tech Stack

- **Next.js** (App Router) + **TypeScript** + **React**
- **GSAP** (scroll + scramble animations)
- **Tailwind CSS**
- **react-icons** + **lucide-react**

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
